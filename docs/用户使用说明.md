# AndroidTVTestToolBox 用户使用说明

本文档介绍 Windows 版 **AndroidTVTestToolBox** 的运行方式、界面、各功能模块用法，以及配置保存与升级说明。

---

## 1. 运行环境与启动

### 1.1 系统要求

- **操作系统**：Windows 10 / 11（64 位）
- **ADB 相关功能**：需能识别已连接的 Android 设备（程序内置 `platform-tools`，一般无需单独安装 adb）
- **串口终端**：需安装 USB 串口驱动；程序依赖 `pyserial`（打包版已包含）
- **部分功能**：条形码预览、截图预览等需要 **Pillow**（打包版已包含）

### 1.2 启动方式

| 方式 | 说明 |
|------|------|
| 便携目录 | 解压 `AndroidTVTestToolBox-Desktop_portable_<版本>.zip` 后，双击 `AndroidTVTestToolBox.exe` |
| 开发/源码 | 在项目根目录执行：`scripts\desktop_dev.bat` |

### 1.3 主界面概览

- **左侧导航**：分组为 **设备**（设备、eMMC测试、Monkey测试、串口终端）与 **工具**（MD5值生成、条形码预览、BASE64、GOTA序列号分割器）；底部 **关于 / 版本** 可查看版本、换肤与检查更新。
- **设备页**：顶部选择 ADB 设备并 **打开** 会话（支持网络 `host:port` 连接）；下方会话标签可多开。每个会话内子页包括：**信息**、**应用**、**Log**、**Shell**、**文件**、**遥控**、**键值判断**。
- **全局通知**：顶部标题栏右侧提供通知铃铛与未读角标，点击可查看历史通知并按状态/设备筛选。
- **eMMC / 串口**：同样以「选择 → 打开会话 → 多标签保活」方式工作；切换左侧导航不会中断已打开的会话。
- **关闭窗口**：可选择缩到系统托盘或退出；正常退出时会自动保存当前界面中的可持久化设置。

## 2. 配置保存位置

### 2.1 保存内容

关闭程序时，以下内容会写入用户配置（路径、选项、快捷命令、串口多标签等）：

- 各工具中的输入框、勾选框、路径
- ADB 快捷命令列表
- ADB 输入多标签（每标签的设备、命令等）
- 串口终端多标签（端口、波特率、日志路径等）

**一般不保存**：设备页当前选中的 ADB 设备下拉项（每次启动需重新选择或刷新；已打开的会话标签会按配置策略处理）。

### 2.2 配置文件路径

| 平台 | 路径 |
|------|------|
| Windows | `<程序目录>\userdata\settings.json`（若程序目录不可写则回退至 `%LOCALAPPDATA%\AndroidTVTestToolBox\settings.json`） |

示例：`C:\Users\你的用户名\AppData\Local\AndroidTVTestToolBox\settings.json`

配置与 **程序安装目录分离**。不同 Windows 用户各自一份配置；路径中的「桌面」等也随当前用户变化（`用户目录\Desktop`）。

### 2.3 升级时保留配置

1. 关闭正在运行的 AndroidTVTestToolBox  
2. 解压新版本便携包覆盖或迁移，**不要删除** `%LOCALAPPDATA%\AndroidTVTestToolBox\` 与原 `<程序目录>\userdata\` 文件夹  

程序文件会被覆盖，用户配置通常保持不变。升级前可复制 `settings.json` 作备份。

## 3. 设备（ADB）

左侧导航 **「设备」**。顶部连接栏可选择在线 ADB 设备并 **打开** / **全部** 打开会话，也可在 **网络** 框输入 `IP` 或 `host:port` 后连接；上方 SN 标签切换设备，下方子页包括 **信息**、**应用**、**Log**、**Shell**、**文件**、**遥控**、**键值判断**。

**信息**：打开会话后默认进入，展示型号、**软件版本**、**DDR / eMMC（剩余、容量、占用比例）**、Android/SDK、构建类型、IP 与 fingerprint 等，可 **复制全部**。

**Log**：支持实时 WebSocket 流式抓取 Logcat、导出 `dmesg` / `dumpsys` / `getprop` / `异常现场`，以及后台非阻塞生成 `bugreport`（带耗时/大小进度条与取消按钮，不影响同时抓取其他日志）。

**文件**：浏览设备目录、拖拽上传/拉取/拖出到电脑（非阻塞悬浮进度卡片，实时显示已传大小、速率与取消按钮）；工具栏 **填充** 可按百分比占用剩余可用空间（优先 `fallocate` 秒级真实占位，不支持时自动回退流式 `dd`；支持后台继续），**释放** 删除这些测试文件。

**遥控**：内嵌 `scrcpy` 实时投屏与录屏（支持 720p/960p/1440p 清晰度切换）、方向键（按住连发与右键长按）、`Enter` 键、中英文文本输入、截图裁剪标注与账号一键填充。

> 下文部分步骤仍沿用旧版「ADB 输入 / 日志抓取」称呼时，对应关系为：ADB 输入 ≈ **Shell**；日志抓取 ≈ **Log 抓取**；常用命令中的安装/文件等已并入 **应用** / **文件** / **界面** 子页。

### 3.1 Shell（原 ADB 输入）

等价于在 CMD 里执行 **`adb shell <命令>`**（每条命令单独起子进程，不是先 `adb shell` 再连续输入；与 `cd`/环境变量持久化行为与 CMD 单次调用一致）。界面中只写 shell 里那部分，不要写 `adb shell` 前缀。

输出为 adb 进程的 **原始字节** 再解码（先试 UTF-8，中文 Windows 下再试 GBK/CP936），避免整段用 UTF-8 替换非法字符导致与 cmd 里看到的不一致。

**基本操作**

1. 在本标签 **设备** 行选择 **ADB 设备**（与顶栏独立，改顶栏不会改已开标签）；必要时点 **刷新设备**  
2. 连接状态由设备行右侧状态指示显示  
3. 在 **发送** 输入框输入命令，按 **Enter** 或点 **发送**  
4. **输出监视** 中 **TX** 为发送的命令、**RX** 为该命令整段回复  
5. 发送后输入框会清空  

**多标签**

- 点击 **+** 新建标签（默认设备为当时顶栏所选，之后各标签可各自切换）；标签标题为设备序列号（同设备多开时显示 `(2)`、`(3)` 等）  
- 点击标签上的 **×** 关闭该标签  

**快捷命令**

- **快捷** 下拉框选择预设，自动填入发送框  
- **管理…** 可增删改快捷项；每条为「显示名称 + shell 命令（不含 `adb shell`）」  
- 出厂默认仅一条：`input text hello`  

**多行剪贴板 / 批量执行**

从别处复制多行命令后，在发送框按 **Ctrl+V**（或 **Shift+Insert**）：

| 剪贴板内容 | 行为 |
|------------|------|
| 一行 | 填入发送框，可编辑后再发送 |
| 多行 | 按行顺序自动执行（无需再点发送） |

支持两种写法（可混用）：

```
input text 122
input text 13363
```

```
adb shell input text 122
adb shell input text 13363
```

也支持 `adb -s 设备号 shell …` 形式；程序会去掉 `adb shell` 前缀，**设备仍以当前标签页所选为准**，不会根据剪贴板里的 `-s` 切换设备。

空行和以 `#` 开头的行会被忽略。

**其它**

- **清空** / **导出**：管理输出区内容  
- 执行结果会同步到底部 **操作日志**（若已连接）  

### 3.2 日志抓取

**日志输出目录**：抓取类文件默认保存位置，可 **浏览…** 修改，**打开目录** 快速查看。未指定时多默认为当前用户 **桌面** 下带时间戳的文件夹。

子功能：

| 子标签 | 功能简述 |
|--------|----------|
| **Logcat** | 按缓冲区 / Tag / 级别过滤；清空缓冲区；单次抓取或持续抓取（可实时预览） |
| **Bugreport** | 生成完整 bugreport（耗时较长，请保持设备连接） |
| **诊断导出** | 导出 dumpsys、getprop、设备信息摘要等 |

### 3.3 常用命令

| 子标签 | 功能简述 |
|--------|----------|
| **安装 APK** | 拖放 APK 或文件夹批量安装（Windows 拖放）；支持覆盖安装 `-r`；查看安装输出 |
| **卸载应用** | 可自动读取设备已安装包名并填入；执行 `adb uninstall`；可选保留数据 `-k`；查看卸载输出 |
| **截图** | 对当前 ADB 设备截图、预览、保存、复制到剪贴板（Windows） |
| **项目信息** | 通过 getprop 读取 Build 相关属性 |
| **文件传输** | Pull（设备→电脑）/ Push（电脑→设备）；在设备上浏览选路径；**填充** / **释放** 可按百分比占用或腾出 eMMC 测试空间 |

## 4. 虚拟遥控器

- **遥控器**：方向键、确认、返回、主页等按键映射为 Android `keyevent`  
- **键盘**：方向键导航；Enter → 确认；**Esc → 返回**；空格 → 确定；Home → 主页  
- **投屏**：使用 scrcpy 嵌入预览（需打包时包含 scrcpy 组件）；可 **开始/停止投屏**  
- **输入文字**：输入后 **发送到设备**（`input text`）  

使用前请在顶栏选择正确 ADB 设备。

---

## 5. 串口终端

- 支持 **多标签**，每标签独立串口、波特率、行尾、日志选项  
- **刷新端口** → 选择串口与波特率 → **连接** / **断开**  
- **Enter** 发送；可设 **行尾**（无 / CR / LF / CRLF）  
- 可选 **自动保存日志** 并指定目录  
- 标签栏 **+** 新建、**×** 关闭；关闭程序时保存各标签配置  

需已安装对应 USB 转串口驱动；无可用端口时请检查设备管理器。

---

## 6. UnifyKey 读写

用于通过 ADB 读写设备上的 UnifyKey。

1. 顶栏选择设备  
2. **读取 Key 列表** 加载可用 Key  
3. 选择 Key，填写 **Key 值**  
4. **读取** 或 **写入并回读**  
5. 可选 **使用 su 执行（推荐）**  
6. 支持 **从文件导入** 键值  

**说明**：Key 名称与 Key 值在关闭程序后 **不会** 自动保存（避免误留敏感数据）。

---

## 7. 条形码预览

- 输入 **条码内容**（Code128），**生成预览**  
- **从 txt 导入** 后可 **上一条 / 下一条** 浏览多行  
- **保存预览图** 将当前预览保存为图片  
- 默认仅在内存预览；保存路径由你指定  

---

## 8. BASE64 加解密

- 左侧输入 Base64 或明文（可 **拖入文本文件**），右侧输出；**加密** / **解密**  
- 可选 **解密后 JSON 美化**；右侧输出框始终自动换行显示（仅显示换行，不改变实际文本）  
- **加密**时若左侧为合法 JSON，会自动压成紧凑格式再 Base64，与「解密 → 交换 → 再加密」时一般可与原密文一致（仅差空白时）  
- **查找** 支持在两侧或单侧范围搜索，上一个 / 下一个  
- **交换**、**清空**、**复制右侧**、**导入左侧…**、**保存右侧…**  

---

## 9. GOTA 序列号分割器

将一个大文本按行数拆成多个文件。

1. 设置 **前缀**（用于生成文件名）  
2. 选择 **输入文件**、**输出目录**  
3. 设置 **每个文件行数**  
4. **开始分割** → **打开输出目录** 查看结果  

输出示例：`<输入名>_serial_001.txt`、`_002.txt` …

## 10. 常见问题

### 10.1 网络 ADB 连接

设备需先开启 **无线调试** 或执行过 `adb tcpip 5555`（视系统版本而定）。

1. 在顶栏 **网络** 框输入 `IP` 或 `IP:端口`（只写 IP 时默认端口 **5555**）  
2. 点 **连接** 或按 **Enter**  
3. 连接成功后点 **刷新**，在下拉框中选择形如 `192.168.1.100:5555` 的设备  
4. **断开**：输入框有地址时断开该地址；留空则断开全部网络设备  

上次输入的 IP 会保存在用户配置中。

### 10.2 找不到 ADB 设备

- 设备是否开启 USB 调试  
- 数据线是否支持数据传输  
- 顶栏点 **刷新**；必要时在系统命令行执行 `adb devices` 对比  
- 仅充电模式可能导致无法识别  
- 网络连接请确认电脑与设备在同一局域网、防火墙未拦截端口  

### 10.3 adb 不可用

- 使用官方打包版本（内置 platform-tools）  
- 杀毒软件是否拦截程序目录  

### 10.4 串口无法连接

- 端口是否被其它软件占用  
- 波特率是否与设备一致  
- 驱动是否正常  

### 10.5 投屏无法启动

- 确认使用完整安装包/构建（含 scrcpy）  
- 关闭占用 adb 的其它工具后重试  

### 10.6 配置丢失或错乱

- 是否误删 `%LOCALAPPDATA%\AndroidTVTestToolBox\`  
- 是否换了 Windows 用户（配置不共享）  
- 从备份恢复 `settings.json`  

### 10.7 路径无效

设置里保存的是 **绝对路径**。换电脑、换用户或桌面被重定向后，需在对应工具中重新 **浏览** 选择目录。

## 11. 卸载与完全清除数据

- **清理程序**：关闭 AndroidTVTestToolBox 后直接删除便携目录即可（默认 **不删除** `%LOCALAPPDATA%` 下的用户配置）  
- **同时清除配置**：手动删除文件夹 `%LOCALAPPDATA%\AndroidTVTestToolBox\`  

---

## 12. 版本与反馈

- 正式打包版本号为 **打包当天日期**，格式 `YYYY.MM.DD`（如 `2026.05.26`）  
- 便携包目录：`AndroidTVTestToolBox-Desktop\`；压缩包形如 `AndroidTVTestToolBox-Desktop_portable_2026.11.12.zip`  
- 升级：解压新包后运行其中的 `升级.bat`（自动保留 `<程序目录>\userdata\` 中的配置/报告/自备包）  
- 旧版 Tk 单机包（`Toolbox` / `Toolbox_portable_*.zip`）已停用，请改用 Desktop 便携包
